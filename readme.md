# Belajar penerapan responsive

## halaman ini merupakan halaman responsive dengan menyesuaikan 3 ukuran layar

halaman ini responsive dimana 
- ketika layar lebih dari 1024px maka bagian navbar akan menjadi flex-row dengan content space-betwen
- ketika layar kurang dari atau sama dengan 1024px maka bagian navbar dan akan menjadi flex-column dengan align item flex-start(posisinya di awal atau sebelah kiri)
- ketika layar kurang dari atau sama dengan 768px maka bagian navbar dan akan menjadi flex-row dengan align item center (jarak antara atas dan bawah di tengah)
